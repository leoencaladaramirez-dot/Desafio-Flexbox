# Sistema de Mensajería

## Resumen del Proyecto
Este proyecto es un **Sistema de Mensajería** diseñado para facilitar la comunicaciónentre usuarios. Desarrollado utilizando **HTML**, **CSS** y **Flexbox**, su objetivoprincipal es ofrecer una interfaz amigable donde los usuarios puedan iniciar chatsy gestionar contactos de manera eficiente.

## Tema de la Semana: Flexbox
Este proyecto fue desarrollado como parte del desafío semanal, cuyo tema principalfue **CSS Flexbox**. A lo largo del desarrollo se aplicaron los conceptos clave deFlexbox, tales como:
- **`display: flex`**: Para estructurar los contenedores principales de la interfaz.- **`justify-content`**: Para alinear los elementos horizontalmente dentro de los  contenedores.- **`align-items`**: Para alinear los elementos verticalmente.- **`flex-direction`**: Para definir la dirección del flujo de los elementos.- **`flex-wrap`**: Para controlar el comportamiento de los elementos cuando no caben  en una sola línea.- **`gap`**: Para gestionar el espaciado entre elementos flex.

## Logros
- **Estructura HTML Semántica**: Utiliza etiquetas HTML5 para una mejor organización  y claridad del contenido.- **Diseño Responsivo con Flexbox**: Implementación de Flexbox para asegurar que la  interfaz se adapte a diferentes tamaños de pantalla.- **Estilo Personalizado**: Aplicación de estilos CSS únicos, incluyendo una paleta  de colores y fuentes que fomentan la legibilidad y la estética del diseño.

## Secciones Clave
- **Estado del Usuario**: Área donde se muestra la información del usuario activo,  incluyendo su nombre y estado.- **Nuevo Chat**: Un botón destacado que permite a los usuarios iniciar un nuevo chat  con un solo clic.- **Lista de Contactos**: Sección que presenta a todos los contactos del usuario,  mostrando sus avatares, nombres y un resumen de mensajes previos.- **Sección Principal**: Contiene un icono de networking y un mensaje de bienvenida  que invita a los usuarios a comenzar a interactuar.
