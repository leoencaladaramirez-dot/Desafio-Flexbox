# Ejercicio Sistema de Mensajería
## Resumen del Proyecto
Este proyecto es un **Sistema de Mensajería** diseñado para facilitar la comunicación entre usuarios. Desarrollado utilizando **HTML**, **CSS** y **Bootstrap**, su objetivo principal es ofrecer una interfaz amigable donde los usuarios puedan iniciar chats y gestionar contactos de manera eficiente.
## Logros
- **Estructura HTML Semántica**: Utiliza etiquetas HTML5 para una mejor organización y claridad del contenido.  - **Diseño Responsivo**: Implementación de Bootstrap para asegurar que la interfaz se adapte a diferentes tamaños de pantalla, mejorando la experiencia del usuario en dispositivos móviles y de escritorio.
- **Estilo Personalizado**: Aplicación de estilos CSS únicos, incluyendo una paleta de colores y fuentes que fomentan la legibilidad y la estética del diseño.
## Secciones Clave
- **Estado del Usuario**: Área donde se muestra la información del usuario activo, incluyendo su nombre y estado.
- **Nuevo Chat**: Un botón destacado que permite a los usuarios iniciar un nuevo chat con un solo clic.
- **Lista de Contactos**: Sección que presenta a todos los contactos del usuario, mostrando sus avatares, nombres y un resumen de mensajes previos.
- **Sección Principal**: Contiene un icono de networking y un mensaje de bienvenida que invita a los usuarios a comenzar a interactuar.
